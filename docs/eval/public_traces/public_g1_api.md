# Public-trace ordering with the hosted-LLM G1 (vertex / gemini-2.5-flash)

This compares orders against the published label. A lower trial count means the order named the labelled agents earlier. It does not mean those agents are a minimal fix, and it does not mean restoring them would make the task pass.

mathchat rows tagged `two_role` are not in these means. The random-order reference is the committed `public_g1.json` one (100 seeds); no new shuffle was run. `api_small` = the laya card budget; `api_big` = 8x budget + GOOD_IN/UPSTREAM/WRITES_ALL where a known-good run exists (on this corpus it never does, so those fields are absent).
`api_full` = no card budget at all: every field in full, no per-field DIFF cap; the only truncation left is the model's own context window (§14 amendment: E3).
